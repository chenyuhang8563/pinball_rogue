# 敌人系统设计

> 状态：**MVP 设计已确认**（2026-08-04，后修订为攻击预警机制）。本文件是敌人系统的权威设计；已确认部分可据此实现，未确认/后续内容标在对应章节。

## 素材资源

- **位置**：`res://Assets/Monsters/`（`Slime.png` 512×256 spritesheet，另有 `fly-Sheet.png`、`monsters.png`）。
- **史莱姆场景**：`res://Combat/battle/enemies/slime.tscn`（继承 `enemy.tscn`，`AnimationPlayer` 在 slime 场景，`Sprite2D` 用 `region_rect` 切帧）。

## 现状（已核实事实）

- 敌人是 `RigidBody2D` 物理木桩：弹珠撞击时按 `get_hit_damage` 掉血，无主动行为。
- 玩家唯一控制：左右挡板，弹珠轨迹不可控（混沌系统）。
- 玩家扣血来源：掉球（`marble_fell` → `RunHealth.damage(1)`，初始 10 血，归零 run 失败）。
- 已有可复用系统：弱点（`weak_point.gd`，方向性暴击）、状态效果（冻结/火/毒/电）、`BattleSession`/`BattleSpawner`/`BattleGroupDef` 战斗生命周期。

## 核心机制：攻击预警（MVP 焦点）

### 规则

- 每个敌人周期性发动一次**范围攻击**。攻击有明确的视觉预警：
  **红色边框 + 红色渐进填充**——填充进度 = 攻击准备进度。
- 预警范围 = 扇形（或其他参数化形状，默认敌人正面扇形，区域锚定，不追踪弹珠）。
- **填充完成 = 攻击发动**：范围内所有弹珠被命中（扣血 + 弹飞）。范围外无事发生。
- **攻击可以被打断**：
  - 球撞敌人任意部位 = 打断：填充清空 + 敌人硬直 0.8s（安全窗口）
  - 打断后 2s 免疫打断（保证敌人总有机会把攻击打完）
  - 操作统一：打球 = 伤害 + 打断，进攻即防守，无需学习新操作
- 攻击发动后 → 敌人进入冷却（安全窗口），随后重新开始填充下一轮攻击。
- 打死敌人 → 攻击永久消失，该位置恢复安全。

### 公平性（核心）

弹珠轨迹是混沌系统，不可消除。因此**要求"弹珠位置/经过某处"的精确控制型公平性不成立**。本机制的公平性来自两个可实现的来源：

1. **预警充分可见**：红边框 + 红填充渐进 = 玩家始终看到攻击准备进度，知道"这个区域马上要炸"。归因清晰：被命中 = "我看到填充快满了，球还在范围内"。
2. **打断 = 主动反制**：玩家不依赖躲避，而是通过打球（撞敌人）主动取消攻击。即使弹珠被迫留在范围内，玩家也有打断这条"兜底反制"，风险可管理。

**决策边界**（玩家的真实选择权）：
- 攻击填充时：把球打向敌人打断攻击（进攻，冒险把球送近）vs 把球带离范围（保守，失去打断机会）。
- 混沌的角色：球能否撞到敌人（打断）是概率性的——把球养在敌人附近 = 打断多但危险近；送远 = 安全但打断少。

### 类型 = 纯参数化

一套攻击预警机制，参数生成所有敌人（无独特机制，MVP 最快）：

| 类型 | 范围 | 填充速度 | 攻击伤害 | 打断冷却 |
|---|---|---|---|---|
| 普通 | 标准扇形 | 标准（如 3s 填满） | 1 血 | 2s |
| 精英 | 大扇区/双方向 | 更快 | 2 血 | 3s |
| Boss | 复合形状 | 快 + 分阶段 | 2 血 | 3s |

> Boss 参数位预留；Boss 独特机制（成对风险等）留到第二阶段，见「未来扩展」。

## 全局扣血机制

- 玩家扣血来源 = 掉球 + **敌人范围攻击命中**，共享同一血条（10 血基线）。
- 攻击命中复用现有管线：`RunHealth.damage(amount)` → 血条 UI → 归零 run 失败。
- 预警填充（红填充渐进）本身承担"预兆标记"职责——即攻击预告的视觉语言，无需额外标记系统。

## MVP 范围

**做：**
- [ ] 攻击预警系统（范围判定、红边框 + 红填充渐进、填充计时、命中扣血+弹飞、冷却）
- [ ] 打断系统（球撞敌人 → 打断 + 硬直 + 免疫冷却）
- [ ] 参数化敌人定义（普通 + 精英两个变体起步，Boss 参数位预留）
- [ ] 扣血管线（攻击命中 → `RunHealth.damage` → 血条 UI，复用掉球路径）
- [ ] 与 `BattleSession`/`BattleSpawner` 整合（攻击随敌人生成/销毁，参数经 `BattleGroupDef.EnemyEntry` 传入）
- [ ] GUT 测试（填充/命中/打断/硬直/免疫冷却/销毁）

**不做：** 成对风险、威胁谱系其他类型、敌方弹幕、进区伤害奖励、玩家献祭交易。

## 未来扩展方向（非 MVP）

- **成对风险（吞夹型）**：张嘴 = 弱点+安全区，闭嘴瞬间夹住球 = 扣血。规则一句话"张嘴打球，闭嘴远离"。已计划为 Boss/重型敌人的独特机制。
- **威胁谱系其他类型**：拍击型（挥击弹开球）、移动型（巡逻改变球路）、构筑型（生成危险地形）、吸附型（减速改变节奏）——均为"物理威胁"（弹飞球不扣血），与攻击预警机制正交。
- **敌方弹幕/投射物**：需要额外公平性设计，当前预警攻击机制已避免该需求。
- **玩家决策交易**：献祭生命换金币等自愿交易，独立于战斗，见讨论记录。

## 讨论记录（决策脉络）

- 敌人威胁方式：排除"敌人直接扣血（弹幕命中）"——弹珠不可控 → 被弹幕打中无法归因 → 失望感。改为"敌人制造需玩家决策的危机"。
- 排除方向：挡板倒计时（回合感、挡板=必需品不该被惩罚）、节拍条（撞击=正收益不该喂敌人）、操作驯服（要求精确引导，混沌下不成立）、危险地形化（球撞地形 = 碰撞不可控 → 扣血仍随机）、禁区逗留计时（复杂化，被修订为攻击预警）。
- 扣血公平性曾在"系统压力/玩家决策/敌人行为"三者间权衡，最终落在"敌人行为（范围攻击）+ 玩家主动反制（打断）+ 预警可见"。
- **修订记录**：初版设计为"禁区 + 逗留计时 + 分段奖励"（自愿冒险进禁区）；用户要求简单化后改为"攻击预警 + 打断"（纯危险区，无进区奖励，反制靠打断）。
