# 分级物品 Tooltip 与术语词典

## 等级与入口

Tooltip 标题不显示等级；描述由 `ITEM_<ID>_DESC_LV1` 至 `LV4` 决定。

- 商店报价使用 `target_level`。
- 奖励的新物品与替换物品使用 Lv1；遗物升级奖励使用 `expected_level + 1`。
- 库存弹珠、遗物、技能槽及战斗 HUD 技能槽使用当前 `ItemProgression.level_of()`。

## 展示规则

- 十三个术语的文字为 `#cead4a`，游戏内不加下划线。
- 火焰、冰霜、雷电、毒素、爆炸伤害只给伤害数字着色；不再按等级改变颜色。
- 仅鼠标悬停术语时显示解释；移出立即隐藏，不支持长按和解释内嵌套悬停。
- 解释卡片在主 Tooltip 下方，同宽、间隔 2px、黑底与中性边框；标题 12px 金色，定义 10px 白色。

## 术语

术语的中英文名称与最终定义由 `translations/item_levels.csv` 的 `TERM_*` 条目和根目录 `CONTEXT.md` 共同维护。

## 定性成本

本次只改变展示、翻译与 Tooltip 数据选择，不调整战斗数值。炸弹半径、火葬半径、热冲击与瘴气的觉醒加成等仍以现有玩法配置为准；文案应如实呈现，不将文案修复反向解释为数值平衡改动。
