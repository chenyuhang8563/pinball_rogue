# 回响流派：动能工坊

> 本文是玩法/美术规格草案，不是实现说明。文中全部数值均为待试玩锚点，须以实际对局反馈校准。
> 当前实现基线（动能工坊）：命中敌人为左右挡板共享蓄力（上限 2 层），带蓄力弹起弹珠消费
> 层数，弹珠弹起更快并武装追加伤害 token —— 即"强力击"。

## 定位与幻想

回响是动能工坊：把每一次反弹与命中都存进挡板，再用一次弹起把积蓄兑换成强力击。玩家的每个动作
都沿一条可见的因果链推进——反弹与命中蓄力 → 挡板弹起兑现 → 强力击提速并武装追加伤害 → 破城锥
令它穿透敌阵。越长、越干净的轨迹，越能换来有分量的终结。

## 印象与关键词

动能、磨轮、锻锤、穿透、蓄势、轨迹、终结。它应像一条越弹越有劲的工坊流水线：每次反弹与命中
都在喂给挡板，最后由强力击一次性兑现。

## 核心循环

命中敌人 → 左右挡板共享蓄力 +0.25（4 次 = 1 层，上限 2 层）；磨轮让墙面/台面反弹也蓄力（每发
反弹充能累计上限 0.5 层）→ 任一挡板成功弹起弹珠时消费蓄力：追加速冲量并武装对应数量的追加伤害
token，即"强力击"；锻锤把反弹计数兑成 token 追加伤害；破城锥使强力击变穿透态、token 逐敌分配 →
下一次敌人命中消费 token 并追加回响伤害。核心决策是"攒满两层红蓄再兑现"，还是"用当前蓄力尽快
强化下一发"。

## 弹珠与遗物协同

| 角色 | 名称 / id | 玩家可感知作用 |
|---|---|---|
| 起点 | 大地弹珠 / `brown_marble` | 命中敌人为左右挡板蓄力（4 次 = 1 层，上限 2 层）；带蓄力弹起消费层数，弹珠弹起更快并武装追加伤害 token，即"强力击"。升级提升回响伤害（2 / 4 / 8）与弹起球速倍率（觉醒 ×2）。 |
| 生成 | 磨轮 / `grindstone` | 墙面/台面反弹也蓄力（+0.05/反弹，每发累计上限 0.5 层）；挡板弹起不充能，堵住自循环。觉醒 +0.10/反弹。 |
| 兑现 | 锻锤 / `drop_hammer` | 与磨轮共用反弹计数；每 3 次反弹，强力击武装 token 追加伤害 +1，封顶 +3。觉醒每 2 次 +1、封顶 +5。 |
| 形态 | 破城锥 / `battering_ram` | 弹起消费蓄力 → 强力击变穿透态，穿深 = 消费层数（1 层穿 1，2 层穿 2）；穿透态 token 逐敌分配。觉醒穿深 ≤3。 |

雏形为大地弹珠和表级共享蓄力；磨轮扩大蓄力来源，锻锤强化兑现，破城锥为高技术玩家提供一发
穿透敌阵的终结。冲刺等辅助只应帮助修正轨迹或保住充能，不能直接制造蓄力。

## 视觉语言

主色为钢灰、琥珀金与灼白的工坊色调，偏金属与热锻质感。共享蓄力直接显示在挡板上：0 层无遮罩、
1 层黄色遮罩、2 层红色遮罩，左右挡板同步显示。蓄力变化只经信号驱动挡板动画（clear/yellow/red），
不在代码中写视觉属性。另在台面边缘显示本发反弹计数，穿透态时在弹珠上叠加穿深刻度。

## 图标方向

大地弹珠为带矿物纹理的褐色圆珠；磨轮为转动的石磨轮盘，轮缘带磨痕；锻锤为悬空待落的锤头，锤面
蓄着火色；破城锥为锥头冲入敌阵、撞出裂痕的锋锥。图标需突出圆形、工坊器物与冲击方向，不使用
冰晶或爆炸云来代替动能语言。

## 特效需求

- 每次反弹/命中增加可数、可听的蓄力反馈：命中为清晰音阶上行，反弹为短促磨石声，音高随档位上行。
- 挡板蓄满一层时，遮罩由黄转红并有一瞬镀亮，提示"可以兑现"。
- 强力击发射时显示一次方向性冲量感（尾迹拉长 + 短暂速度拖影），命中点留下圆形波纹。
- 穿透态中球穿过敌人而非弹开，每穿过一名敌人消费 1 个 token，命中点留下清晰的穿透波纹。
- token 命中时在敌人身上出现一个短促爆点，与普通命中区分。

## 溅射物/区域/实体规则

穿透态由破城锥触发，是本发内强力击的球体状态：球穿过敌人而不弹开，可连续命中。同一敌人一次
穿越只结算一次主要命中，避免在重叠区域重复结算；穿透态消耗的武装 token 逐敌分配，每穿过 1 名
敌人消费 1 个 token，token 不足时不再分配追加伤害。

磨轮的反弹充能是附加蓄力来源：每发（一次弹起到下一次挡板弹起之间）由墙面/台面反弹累计的蓄力
上限 0.5 层，超过即不再累计，防止纯弹射永动；挡板弹起本身不充能。

## 反馈与可读性

回响需要明确展示四件事：蓄力档位（挡板黄/红遮罩）、本发反弹计数（台面边缘刻度）、当前穿深
（穿透态弹珠上的刻度）、token 剩余（弹珠附近的发光计数）。这些读数须与毒的圆形孢子区、火的
冲击波区分开，避免台面误读。

## 平衡边界

回响收益来自保球和操作质量，不能由普通命中快速充满。共享蓄力上限 2 层，每层对应一次待结算
伤害 token；磨轮反弹充能每发上限 0.5 层、挡板弹起不充能，防止纯弹射永动。穿透态穿深 ≤2
（觉醒 ≤3）；token 逐敌分配、同一敌人一次穿越只结算一次。token 随当前链生命周期存在（掉球重建
链后清零，挡板蓄力保留）。球速倍率与回响伤害由统计驱动：`echo_flipper_speed_multiplier`
（默认 1.5）与 `echo_bonus_damage`（2 / 4 / 8）。

## 与其他流派的桥梁

回响本轮暂不设跨流派桥梁（用户决策）：不推出连接其他流派的专属遗物，也不依赖外部桥接来成立。
其他流派的桥接件可自然地与回响的物理弹跳共存，但允许普通共存，不强造专属联动。

## 待确认问题

1. 磨轮反弹充能限流值（+0.05/反弹、每发累计上限 0.5 层）是否足以压住纯弹射永动，又不会让磨轮显得无用？
2. 破城锥的穿深（≤2，觉醒 ≤3）与 token 逐敌分配的结算手感是否顺畅？同一敌人一次穿越只结算一次是否会被玩家感知为"漏伤"？
3. 锻锤"每 3 次反弹 +1、封顶 +3"（觉醒每 2 次 +1、封顶 +5）的节奏是否与磨轮反弹计数配套舒适？
4. "憋满两层红蓄再兑现"与"用当前蓄力尽快强化下一发"的抉择强度是否足够，两种玩法是否有清晰收益差？
5. 强力击的追加伤害（`echo_bonus_damage` 2 / 4 / 8）随穿透多敌分配后是否被放大到超标？
