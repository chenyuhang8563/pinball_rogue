# 雷电流派：蓄弧复击

> 本文是玩法与表现规格草案，不是实现说明。Lv1～Lv3 与觉醒数值均为首轮试玩锚点，须以实际命中频率、单发时长和敌人生命分布校准。

## 1. 设计结论

新版雷电不再以“带电敌人靠近后自动联网”为核心，而是强调由弹珠轨迹主动完成的两拍循环：

1. 第一次命中给敌人留下**电弧**；
2. 再次命中带有电弧的敌人，立即造成额外雷电伤害；
3. 连续复击会把电弧层数和伤害推高，换目标则重新铺设；
4. 遗物把复击收益扩展为分叉、蓄压、续流和雷暴。

流派幻想是“玩家亲手把弹珠轨迹闭合成高压回路”。它应奖励连续命中、路线规划和目标选择，不依赖其他流派提供聚团、控制或元素反应。

## 2. 定位与关键词

**定位：** 短窗口叠层、复击爆发、单体升压、有限扩散。

**关键词：** 充电、复击、层数、击穿、分叉、续流、雷暴。

雷电的基础强度来自“能否再次打中同一目标”，而不是每次命中都无条件附送范围伤害。对单体时可持续升压；面对敌群时，需要先铺电弧，再通过闪电链与雷暴兑现。

## 3. 新增弹珠：闪电弹珠 `lightning_marble`

### 3.1 基础效果

闪电弹珠直接命中敌人时：

- 若目标命中前没有电弧：本次只施加 1 层电弧；
- 若目标命中前已有电弧：按命中前的层数造成一次额外雷电伤害，随后再施加 1 层电弧；
- 施加电弧会刷新该目标的电弧持续时间；
- 普通上限为 3 层，超过上限的层数不保留。

因此，无遗物时连续命中同一敌人的层数变化为 `0 → 1 → 2 → 3 → 3`，额外雷电伤害依次按 `0 / 1 / 2 / 3 / 3` 层计算。

### 3.2 等级与觉醒

| 等级 | 效果 |
|---|---|
| Lv1 | 每层电弧造成 **2** 点额外雷电伤害；电弧持续 **5 秒**；上限 3 层 |
| Lv2 | 每层电弧造成 **3** 点额外雷电伤害；其余规则不变 |
| Lv3 | 每层电弧造成 **4** 点额外雷电伤害；其余规则不变 |
| 觉醒 | 保留 Lv3 数值；命中前已有电弧时，本次复击结算后改为施加 **2 层**电弧。首次充电仍只施加 1 层 |

觉醒后的连续命中层数变化为 `0 → 1 → 3 → 3`，将满压所需命中数从 3 次缩短到 2 次，但不会提高层数上限。

## 4. 雷电系 Debuff：电弧

### 4.1 核心规则

| 项目 | 规则 |
|---|---|
| 类型 | 附着在单个敌人身上的可叠层短时 Debuff |
| 基础上限 | 3 层；仅“莱顿瓶”可以提高上限 |
| 持续时间 | 5 秒；每次新增层数时整体刷新 |
| 基础来源 | 闪电弹珠直接命中；遗物只有在条目明确说明时才能施加 |
| 基础触发 | 仅闪电弹珠的直接碰撞命中触发额外雷电伤害 |
| 消耗 | 普通复击不消耗层数；自然到期、敌人死亡或“莱顿瓶”击穿时移除 |
| 伤害类型 | 独立的次级雷电直伤，不算第二次弹珠碰撞 |

“电弧”是状态名；闪电弹珠依据电弧层数造成的额外伤害统一称为**复击放电**。两者必须在文案、统计和表现中保持区分。

### 4.2 单次命中结算顺序

1. 在接触瞬间记录目标命中前的电弧层数；
2. 结算闪电弹珠本身的碰撞伤害；
3. 若目标仍存活且记录层数大于 0，先确定莱顿瓶是否击穿，再结算一次复击放电；
4. 若目标仍存活，处理莱顿瓶的旧层清空，随后施加本次应获得的电弧层数并刷新持续时间；
5. 若本次发生复击放电，完整结算闪电链及其施加的电弧；
6. 将本次直接复击计入雷暴核心；若达到阈值，在闪电链结算完成后快照雷暴目标，再执行落雷。

同一次物理接触对同一敌人最多触发一次复击放电。闪电链、续弧继电器、雷暴等次级伤害不会再次触发复击放电，也不计作新的弹珠命中。

续弧继电器属于死亡响应：每个伤害实例造成死亡后立即结算。若它发生在雷暴快照之前，新接收电弧的敌人可以进入本次雷暴候选；雷暴开始后目标列表冻结，落雷击杀所产生的续弧不会插入或改写本轮目标。

### 4.3 状态反馈

- 1～3 层使用贴附在敌人轮廓上的分段蓝白电环表示，每层对应一个清晰节点；
- 莱顿瓶提高上限后，电环最多显示 6 个节点，不以多个同心大环遮挡敌人；
- 剩余时间低于 1 秒时，电环由稳定脉冲转为断续闪烁；
- 复击放电使用从电环收束到命中点的短促白芯电流，必须与普通碰撞区分；
- 满层时节点闭合成一圈，并出现低频蓄压声，提示继续复击已处于最高稳定收益。

## 5. 四件遗物总览

| 角色 | 名称 / id | 核心作用 |
|---|---|---|
| 铺设 | 闪电链 / `lightning` | 复击放电时向其他敌人分叉，铺开新的电弧目标 |
| 升压 | 莱顿瓶 / `leyden_jar` | 提高电弧层数上限，强化持续复击的单体收益 |
| 续流 | 续弧继电器 / `arc_relay` | 带电敌人死亡时转移层数，避免铺设成果随击杀浪费 |
| 兑现 | 雷暴核心 / `thunderstorm` | 单发内完成足够多次复击放电后，对带电敌群落雷 |

四件遗物只在玩家拥有闪电弹珠后进入奖励池。首轮设计不提供跨流派标签、桥梁遗物或由其他元素触发电弧的规则。

## 6. 闪电链 `lightning`

### 6.1 定位与效果

闪电链是铺设件。每当闪电弹珠触发一次复击放电，从该目标向范围内其他敌人发射分叉闪电。分叉优先选择**没有电弧**的敌人，其次选择电弧层数最低的敌人，同层时选择距离最近者。

每条分叉造成固定雷电伤害并施加电弧，但不会触发目标已有电弧的复击放电。

### 6.2 等级与觉醒

| 等级 | 效果 |
|---|---|
| Lv1 | 向 **1** 名敌人分叉，范围 **120**，造成 **2** 点雷电伤害并施加 1 层电弧 |
| Lv2 | 向最多 **2** 名不同敌人分叉，范围 **140**，每名受到 **3** 点雷电伤害并获得 1 层电弧 |
| Lv3 | 向最多 **3** 名不同敌人分叉，范围 **160**，每名受到 **4** 点雷电伤害并获得 1 层电弧 |
| 觉醒 | 保留 Lv3 数值；分叉命中时改为施加 **2 层**电弧 |

### 6.3 边界与表现

- 不允许选中触发分叉的源目标，也不在目标不足时来回跳转；
- 一次复击放电只生成一组分叉，分叉本身不能再次生成闪电链；
- 闪电链始终在雷暴目标快照前完整结算；本次分叉新施加电弧且仍存活的敌人，可以被同一次复击触发的雷暴选中；
- 多条分叉按约 0.05 秒间隔依次出现，目标顺序应可追踪；
- 图标为一道主闪电在中央节点处分成三支，觉醒后分叉端点增加双层电荷环。

## 7. 莱顿瓶 `leyden_jar`

### 7.1 定位与效果

莱顿瓶是单体升压件。它不提供免费层数，而是提高每个敌人能够储存的电弧上限，让连续复击同一目标获得更高峰值。

### 7.2 等级与觉醒

| 等级 | 效果 |
|---|---|
| Lv1 | 电弧层数上限由 3 提高到 **4** |
| Lv2 | 电弧层数上限提高到 **5** |
| Lv3 | 电弧层数上限提高到 **6** |
| 觉醒 | 保留 Lv3 上限；命中前目标已达 6 层时触发“击穿”：本次复击放电伤害变为 **150%**，随后清空旧层数，再按本次命中重新施加电弧 |

以 Lv3 闪电弹珠为例，6 层普通复击放电为 24 点；觉醒击穿为 36 点。击穿后，普通闪电弹珠留下 1 层，觉醒闪电弹珠留下 2 层。

### 7.3 边界与表现

- 只有命中开始时已经满 6 层才触发击穿；本次命中刚好补满不会立刻击穿；
- 清空发生在本次复击放电结算后、当次命中重新施加电弧前；它不影响本次伤害的层数快照，后续闪电链与雷暴读取重新施加后的状态；
- 击穿不是范围伤害，也不会自动触发雷暴或闪电链之外的新事件；
- 遗物外观为装有蓝白电液的玻璃瓶，等级提升时瓶身金属箍由 4 段增至 6 段；觉醒击穿表现为瓶内白芯瞬间贯穿。

## 8. 续弧继电器 `arc_relay`

### 8.1 定位与效果

续弧继电器是节奏维持件。带有电弧的敌人死亡时，继电器读取其死亡前层数，向范围内一名其他敌人发射续弧，造成固定雷电伤害并转移部分层数。

目标优先级为：没有电弧的敌人 → 电弧层数最低的敌人 → 距离死亡位置最近的敌人。

### 8.2 等级与觉醒

| 等级 | 效果 |
|---|---|
| Lv1 | 范围 **140**；造成 **4** 点雷电伤害，并转移最多 **1 层**电弧 |
| Lv2 | 范围 **160**；造成 **6** 点雷电伤害，并转移最多 **2 层**电弧 |
| Lv3 | 范围 **180**；造成 **8** 点雷电伤害，并转移死亡目标的**全部电弧层数**，但不超过接收目标上限 |
| 觉醒 | 保留 Lv3 数值；续弧同时选择最多 **2** 名不同敌人，每名都获得完整的可转移层数并受到 8 点雷电伤害 |

### 8.3 边界与表现

- 每个死亡敌人最多触发一次续弧继电器；没有合法目标时层数正常消失；
- 续弧伤害可以击杀目标，但由该伤害造成的死亡不会再次触发继电器，防止无操作递归清场；
- 转移只复制死亡瞬间仍存在的层数，不继承剩余持续时间，接收目标重新获得完整 5 秒持续时间；
- 觉醒的两个目标各自获得完整层数，属于觉醒新增的“分流复制”，不是把层数平均分配；
- 图标为两端接点之间吸合的机械继电器；场上表现使用从死亡位置延迟 0.1 秒跃出的细长余电，明显弱于闪电链主分叉。

## 9. 雷暴核心 `thunderstorm`

### 9.1 定位与效果

雷暴核心是单发兑现件。它只统计当前这发闪电弹珠完成的**直接复击放电次数**。达到阈值时，本发最多触发一次雷暴，依次打击场上带有电弧的敌人。

雷暴优先选择电弧层数最高的敌人；层数相同时，优先选择距离当前弹珠最近者。

雷暴在触发它的直接复击完成状态更新、闪电链与其死亡响应全部结算后，快照本轮合法目标。快照完成后，本轮目标和顺序不再变化。

### 9.2 等级与觉醒

| 等级 | 效果 |
|---|---|
| Lv1 | 本发第 **6** 次复击放电时触发；打击最多 **3** 名敌人，每名受到 **6** 点雷电伤害 |
| Lv2 | 本发第 **5** 次复击放电时触发；打击最多 **4** 名敌人，每名受到 **9** 点雷电伤害 |
| Lv3 | 本发第 **4** 次复击放电时触发；打击最多 **5** 名敌人，每名受到 **12** 点雷电伤害 |
| 觉醒 | 保留 Lv3 首轮落雷；0.2 秒后对同一批仍存活的目标追加第二轮 **6** 点落雷，并施加 1 层电弧 |

### 9.3 边界与表现

- 计数在每发弹珠进入台面时清零，离场时废弃；不跨弹珠、不跨发保存；
- 闪电链、续弧继电器、雷暴自身造成的伤害都不增加计数；
- 雷暴触发时目标不足则只打击现有合法目标，不保留剩余雷击；
- 本次闪电链刚施加电弧的存活目标可以进入雷暴快照；快照后的续弧新目标只能参与后续攻击，不能补入本轮落雷；
- 雷暴伤害不触发复击放电或闪电链，但击杀带电目标时可以正常触发一次续弧继电器；
- 首轮雷击按 0.08 秒间隔由高层向低层落下；觉醒第二轮使用更细的紫白雷柱，避免两轮视觉混成一次闪白；
- 图标为封在圆形金属核心中的小型雷云，四枚计数节点环绕外圈；觉醒后核心下方出现第二道较细雷痕。

## 10. 核心循环与组合关系

### 10.1 无遗物

闪电弹珠先命中一次铺设电弧，再通过回弹复击同一目标逐步升到 3 层。玩家在“继续追同一目标提高单体伤害”和“转向新目标铺设下一处电弧”之间选择。

### 10.2 两件成型

**闪电弹珠 + 闪电链**构成基础群体雏形：复击一个目标时为其他敌人预先铺电，后续路线经过这些敌人即可立即放电。

**闪电弹珠 + 莱顿瓶**构成基础单体雏形：更长的连续命中换取更高的每次复击伤害，适合精英与 Boss。

### 10.3 四件完整循环

1. 以闪电弹珠给首个目标充电；
2. 复击触发闪电链，为敌群铺设电弧；
3. 路线切换到已铺设目标，快速累计雷暴次数；
4. 死亡目标的层数由续弧继电器转移，不让网络随清杂中断；
5. 雷暴在本发后段统一兑现，莱顿瓶则持续处理仍存活的高血量目标。

| 组合 | 产生的玩法 | 必要限制 |
|---|---|---|
| 闪电链 + 雷暴 | 更快获得多个可复击目标，再以单发次数触发群体兑现 | 分叉本身不计雷暴次数 |
| 莱顿瓶 + 雷暴 | 单体连续复击也能达到雷暴阈值，兼顾 Boss 与残余杂兵 | 雷暴每发一次 |
| 闪电链 + 续弧继电器 | 前期铺层、击杀后转层，使敌群电弧持续滚动 | 继电器伤害死亡不递归 |
| 莱顿瓶 + 续弧继电器 | 高层目标死亡后把大量层数带入下一目标 | 接收层数受上限约束 |

## 11. 共用视觉与声音语言

### 11.1 色彩与形状

- 主色：蓝白电芯、群青外晕、少量紫色高压边缘；
- 形状：短折线、分叉、闭合节点、细长雷柱；
- 禁止用大面积持续发光代替层数，不让整张台面长期被蓝色滤镜覆盖；
- 闪电弹珠内部应有三枚基础电荷节点，觉醒后节点之间形成双重旋转电弧。

### 11.2 事件层级

| 层级 | 视觉 | 声音 |
|---|---|---|
| 施加电弧 | 敌人轮廓新增一个电荷节点 | 短促“咔”声，音高随层数上升 |
| 复击放电 | 节点向碰撞点收束一次白芯电流 | 干脆电击声 |
| 闪电链 | 从源目标向外展开细分叉 | 连续但错开的跳火声 |
| 击穿 | 目标内部由上至下贯穿粗白线 | 低频蓄压后爆裂 |
| 续弧 | 从死亡位置飘出的细长余电 | 衰减尾音 |
| 雷暴 | 先同步暗场脉冲，再按顺序落雷 | 低沉雷声，觉醒第二轮音量较低 |

## 12. 平衡边界

- 雷电的首击只有铺设价值；若无法复击，基础收益应低于无条件增伤流派；
- 3 层基础上限确保无遗物时 Lv3 复击放电封顶为 **12** 点，避免短窗口无限滚高；
- 莱顿瓶以更长升压时间换取最多 6 层，不同时提供扩散、保层或减阈值；
- 闪电链擅长铺设，不得回跳源目标或在单体环境中凭空增伤；
- 续弧继电器只维持已有层数，不凭死亡制造超过觉醒规则的无限复制链；
- 雷暴以单发直接复击次数作为操作门槛，并保持每发一次；
- 所有次级雷电必须带有来源标记和生成上限，默认不能触发自身或互相递归；
- 电弧持续时间、复击每层伤害、雷暴阈值三者是主要调节阀，不应在同一次平衡调整中同时放宽。

## 13. 首轮试玩验证

至少分别验证以下场景，不能只用满配构筑判断强度：

1. **单个高血量目标：** 无遗物、莱顿瓶 Lv3、觉醒莱顿瓶三档，确认升压时间与击穿周期；
2. **三个分散敌人：** 闪电链是否能铺设但不会自动完成全部输出；
3. **六个普通敌人：** 续弧继电器能否减少击杀后的节奏断档，同时不形成自动清场；
4. **长单发轨迹：** 雷暴 Lv1～Lv3 的阈值是否分别对应困难、稳定、成型三档；
5. **四件觉醒满配：** 确认分叉、续弧和双轮雷暴在密集敌群中仍可追踪，且没有次级触发递归。

建议记录：每发闪电弹珠直接命中数、复击放电数、平均/最高电弧层数、因到期损失的层数、四件遗物各自伤害占比、雷暴触发率与单次目标数。

## 14. 旧设计迁移说明

- 现有遗物 `lightning` 保留内容 id，但从“无条件命中跳链”重做为本文的复击分叉遗物“闪电链”；
- 旧稿的“极化”不再作为独立遗物：其铺设职责由闪电弹珠原生的电弧 Debuff 承担；
- 旧稿的邻近导电网络、自动周期放电和距离连线全部移除；
- `thunderstorm` 保留雷暴身份，但触发条件改为单发内的直接复击次数，不再检查敌人邻近关系；
- 本版不纳入带电球或任何火、毒、冰、回响、爆破桥梁，后续若需要跨流派联动应另案设计。

## 15. 待试玩确认

1. 5 秒电弧持续时间是否足以支持正常回弹复击，又不会让换目标几乎没有代价？
2. 闪电弹珠每层 2/3/4 点的成长，是否能让首击铺设与后续复击形成清楚的伤害差？
3. 莱顿瓶提高到 6 层后，Boss 战是否出现过长预热或过高常驻伤害？
4. 雷暴 6/5/4 次阈值与 3/4/5 个目标上限，是否匹配实际单发命中频率和敌群规模？
5. 满配时是否仍能从表现上分清复击放电、闪电链、续弧和雷暴四类来源？
