# 敌人扣血建立在"预警可见 + 打断反制"上，而非"可控躲避"

弹珠轨迹是混沌系统，玩家无法精确控制弹珠位置。因此任何要求"弹珠不在某处/弹珠经过某处"的扣血机制（弹幕躲避、危险地形、引导打断）在混沌下都会退化为随机惩罚，玩家被扣血时无法归因，产生失望感。

我们因此决定：敌人攻击扣血的公平性不来自"玩家能控制弹珠"，而来自两个可实现来源——**预警可见**（攻击发动前始终以红边框+红填充渐进可见，玩家预判何时危险、被命中时归因清晰）与**打断反制**（弹珠撞击敌人即可取消攻击，即使弹珠被迫留在范围内，风险也可管理）。

_Considered Options_:
- 弹幕躲避型：被弹幕命中扣血。被否——弹珠不可控，命中与否与玩家能力无关。
- 危险地形型：弹珠撞上危险地形扣血。被否——弹珠乱滚撞上地形是常态，扣血仍随机。
- 引导打断型：前摇期引导弹珠击中弱点打断攻击。被否——前摇期间弹珠可能在台面任何角落，"引导"无法保证。
- 禁区逗留计时型（初版）：弹珠进入风险区逗留计时，满时反击。被否/修订——分段奖励复杂化，简化为周期攻击预警。

_Consequences_: 所有敌人风险机制必须让攻击"可预警、可打断"，而非要求弹珠位置精确。敌方投射物/弹幕类攻击需要额外的公平性设计，当前攻击预警机制刻意避免了这类需求。
